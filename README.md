# TradeSpark - Professional AI Trading Assistant

TradeSpark is a high-performance AI trading assistant web application built with React, Vite, Tailwind CSS, and TypeScript.

## Features

- **Live Market Overview Ticker**: Multi-category ticker tape (OTC, Crypto, Forex, Indices, Stocks) with real-time quote refresh and interactive mini sparkline graphs.
- **24/7 OTC Market Mode**: Real-time OTC options trading mode supporting Quotex and Pocket Option feeds with Smart Money Concept (SMC) order block analytics and payout tracking (up to 95%+).
- **Integrated Broker Terminal**: Embedded in-app trading desk for Quotex and Pocket Option featuring a live ticking price engine (800ms updates), interactive canvas chart, timeframe selector (5s, 1M, 5M), investment amount controls, and instant digital options execution (CALL/PUT).
- **Full-Screen Web Desk**: Modal full-screen workstation with live feedback and SSL security address bar.
- **AI Vision Chart Scanner**: Dual-engine chart diagnosis (Standard Forex with automated SL/TP and R:R ratios; OTC Binary with contract expiry and SMC rationale). Features dynamic candlestick visualization with an animated scanning laser.
- **Active Algorithmic Signals**: Filterable real-time signals with detailed parameter cards, expandable institutional strategy theses, and one-tap setup copying to clipboard.
- **Verified Analytics & Win Rate**: Real-time performance breakdown showcasing overall win rates (92.4%), total trades, return metrics, and category statistics.
- **Trader Profile Management**: Plan status, broker connections, and algorithmic execution settings.

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
